# AI Agent Guide for my-profile

## Project overview
- Static personal profile/site built with plain HTML.
- No JavaScript framework, no build tools, no package manager files.
- Main content lives in:
  - `index.html`
  - `week2-cafe.html`
  - `week3-profile.html`
  - `week4-goods.html`

## What to focus on
- Keep changes compatible with a simple static site.
- Improve HTML structure, accessibility, semantic markup, and navigation.
- Avoid introducing dependencies, build tooling, or backend logic.
- Prefer small, self-contained edits to the existing files.

## Environment notes
- The repo includes `.vscode/settings.json` for Live Server port `5501`.
- There is no existing README content to link, so use file names and page context directly.

## When asked to change the project
- Update the relevant HTML file(s) only.
- Preserve plain HTML semantics and simple relative linking.
- If adding styles, keep them inline or in an existing style block rather than adding a new build system.

## File hints
- `index.html` is the entry point.
- `week2-cafe.html`, `week3-profile.html`, `week4-goods.html` are additional static pages.
